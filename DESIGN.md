# Menu bar design

The user-provided macOS Tahoe menu-bar specification is the reference. Mode: Operate. Extend WinRust with a separate native component, preserving existing shell components.

Use a quiet, full-width top-edge Mica surface, 28 logical pixels tall (24-pixel content with usable targets), DPI scaled from monitor geometry. Segoe UI at 13 logical pixels is the Windows system-font equivalent; the active app uses regular weight. Icons use Segoe Fluent Icons. System appearance determines light/dark material and text. DWM controls material fallback, transparency and accessibility policy.

The user confirmed both standard Mica and Acrylic as settings options for the bar. Mica remains the bar default; persist the choice. Context menus always use Acrylic independently. Status artwork is 13 logical pixels within the original 32-pixel targets. The user's requested padding means smaller artwork within targets, not wider spacing between icons.

Application menus occupy the left; essential system controls and a locale-aware clock anchor the right. Overflow moves whole menus into More. Popups follow the user's Windows 11 context-menu screenshot: rounded Acrylic windows, 32-pixel rows, regular 14-pixel type, a consistent icon/check gutter, right-aligned shortcuts and separate trailing chevrons. Native buttons supply accessible names, roles and focus. Hover and keyboard selection use a borderless translucent-white rounded fill, with no dotted focus rectangle. High Contrast retains native selection colors. No idle motion. Hover switches open menus; Escape unwinds submenus; arrows navigate and Enter activates.

Control Center opens from the clock and the Control Center icon. Follow the user's tiled reference: Wi-Fi, Bluetooth, mirroring, media, Focus, display/project, full-width brightness and sound, utility tiles and a settings footer. Each tile is its own rounded Mica HWND, owned by the bar; never paint a large panel behind them. Wi-Fi and Focus retain labels, the footer reads Open Settings, and the remaining controls are icon-only. Keep network information beneath Wi-Fi, and retain names, media metadata and values for accessibility. Center icons and sliders in the space freed by removed labels. Preserve visible desktop gaps. Sliders use transparent custom artwork over native trackbar input/accessibility. Actual media and monitor capability determine enabled states. Unsupported brightness has a disabled slider and a settings icon. No synthetic media or device states. Notifications remain in the Windows system menu. Dropdown context menus remain Acrylic.

Latest refinement: the footer is an **Open Settings** text button. The bar and each tile have a subtle one-physical-pixel lower hairline. A 30% neutral wash reduces Mica's wallpaper tint toward the taskbar's quieter appearance; it supplements native Mica rather than replacing it. Apply the same wash to child-control buffers so there are no rectangular material seams. Actual Wi-Fi/Bluetooth radio state, active Focus session and media playback select an accent-colored tile background. Action launchers and continuous brightness/volume controls have no invented on/off state. Respect High Contrast and preserve borderless hover selection.
